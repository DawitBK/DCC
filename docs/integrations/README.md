# Social platform integration notes (Woluman)

One file per network: `facebook.md`, `instagram.md`, `linkedin.md`, `youtube.md`, `tiktok.md`, `x.md` (task W-04). For each, record:

1. Developer app and business verification steps, who applied, date, current state.
2. Permissions/scopes needed and the review process and typical time.
3. What Postiz supports for it today, tested: **supported / partially supported / unavailable**.
4. Rate limits, quotas, costs and known limitations (for example private-viewing limits for unaudited TikTok apps, X API pricing).
5. What security signals the network exposes (login history, admin changes) and which need manual review.

Official developer documentation is the authority; note the date you read it. No scraping or browser automation, ever.
