| D-22 | Which engine identifier settles a stuck publication (H-11)       | **Proposed 2026-11-21, revised 2026-11-23 after reading the Postiz source; owner decides.** Match on what the engine returns, not on a key stamped into the post: Postiz cannot carry one (a tag attaches only if that tag already exists in the engine, and the post's `group` is generated by Postiz). It does return, for every post, the channel, the stored text, the network's own post id (`releaseId`) and how the post was created (`creationMethod`); DCC now maps all three (pull request for `feature/dawit/engine-evidence-and-analytics`). DCC's idempotency key stays the lock that stops a second send; it is not the identifier that settles one. A stuck publication is matched on channel + the approved version's text (markup and white space removed) + a time window around the attempt. The content id is not used (it repeats across accounts and versions), nor is the engine's operation id alone (it does not exist after a timeout). A post whose `creationMethod` is anything but `api` was not sent by DCC. Settling rules, from [BYPASS-PREVENTION](../engine/BYPASS-PREVENTION.md): one unique match marks the key done; proof the engine refused it marks the publication failed and releases the key; anything unclear stays blocked and goes to a person; never clear a key because it is old; the resolver, time, evidence and reason are audited in the same transaction. "Cancelled" is only for scheduled posts. **Two gaps in today's code that H-11 must close** (checked 2026-11-23): a publish that times out is saved as `pending` with no engine id, and `reconcile` only reads rows that have one, so those rows are never settled; and a crash between the engine accepting a post and DCC saving its row leaves the key `in_progress` with no publication row at all. **Not verified until the first real post (W-03):** the format the text comes back in (HTML or plain). Until then a match that is not exact stays blocked, which is the safe side. A stamped field could be added later in the Postiz fork (W-08 work); the pilot does not need it |
