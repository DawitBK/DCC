- Git Bash rewrites `\\\\server\\share` paths: run anything with a network path from PowerShell. Backticks inside bash `node -e` strings break: write a file instead.
- A session of `dev:session` expires after 30 minutes without use; a long browser run needs a fresh session per context (the screens-pass script does this).
- The registration of the audit checkpoint task and any task that changes the owner's PC was refused by the permission check: give the owner the one command (`scripts/windows/register-audit-checkpoint-task.ps1 -TaskName DCC-Mirror-Audit-Checkpoint -CopyDir '\\\\wsl.localhost\\Ubuntu-24.04\\home\\dawit\\dcc-audit-checkpoints\\mirror' -KeyFile 'wsl:~/dcc-audit-checkpoints/seal.key'`).
