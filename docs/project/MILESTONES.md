# Milestones

Owner: Dawit. **No calendar dates are set here:** the project lead sets them. The proposal plans eight weeks to go-live; the team document defines five phases. This maps the gates;
the first honest check is whether eight weeks still holds given that network API approvals and the open decisions are outside the team's control.

| Gate                           | Phase (team document) | Exit criteria                                                                                                                           | State                     |
| ------------------------------ | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| **M0 Foundation**              | 1                     | Repository, ownership, CI, identity, tenancy, audit, engine interface, onboarding tasks ready                                           | in review (foundation PR) |
| **M1 Discovery done**          | 1                     | Group structure, account inventory (private), stakeholders, current processes, approval matrix and policy signed off                    | not started (Abenezer)    |
| **M2 Design approved**         | 2                     | HTML prototype tested and approved; module plan approved; Postiz assessment and adapter proven live; open decisions D-01..D-08 answered | not started               |
| **M3 Foundation live in test** | 3                     | Test environment with SSO login, registry, memberships, audit working; production secrets approach decided                              | not started               |
| **M4 Release 1 in UAT**        | 3-4                   | Approval workflow, publishing through Postiz for the first networks, registry, audit, reports demonstrated end to end                   | not started               |
| **M5 Security cleared**        | 4                     | Penetration test and incident simulation: no open critical/high findings; audit chain verified; tenant isolation re-tested              | not started               |
| **M6 Pilot and go-live**       | 5                     | UAT signed, training delivered, runbooks accepted, rollback rehearsed; pilot companies onboarded                                        | not started               |

Release 2 (TikTok and X, if their approvals arrive; AI monitoring) follows the proposal's plan and depends on external approvals.
